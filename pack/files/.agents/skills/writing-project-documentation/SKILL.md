# Writing Project Documentation

From the repository root, read `.agents/guidelines/documentation.md` before
substantial project-documentation work.

Follow the applicable `AGENTS.md` files and `.agents/project.md` first. Treat
`docs/project/` as live project documentation and `docs/templates/` as managed
reference material as defined by the canonical guidance.
