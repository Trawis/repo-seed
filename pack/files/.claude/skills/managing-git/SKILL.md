# Managing Git

From the repository root, read `.agents/guidelines/git.md` before performing Git
or pull-request operations that require branch, commit, push, or PR decisions.

Follow the applicable `AGENTS.md` files and `.agents/project.md` first. Use the
canonical Git guidance rather than duplicating it in this skill.
